RELIASTRAcli · terminal design system · v0.1.0 · proposal

The UI that appears in a developer's terminal. Every screen below is drawn on a real character grid with IBM Plex Mono, and nothing inside the terminal surface is drawn that a terminal cannot print — no rounded pills, no shadows, no gradients in the output. The premium is in the discipline: one accent for identity, four semantic inks for verdicts, one reserved ink for provenance, alignment as the layout system, and micro-charts built from block elements.

Principles why it looks like this

01Restraint over decoration

Brand blue marks identity and interaction only. Semantic inks mark verdicts only. Everything else is a four-step neutral ramp. Rainbow output is the generic look; this is not it.

02Structure from rules, not boxes

Ruled section headings, aligned kv blocks, right-aligned numerics, a 2-column gutter. ASCII box-drawing frames are banned from output: they fight wrapping, diffs and screen readers.

03The honesty contract, in the layout

A verdict always carries its scope. Attribution prints as a weighted score beside its methodology version, never as a cause. One observation point is labelled as one. Missing fields are —, never 0.

04One code path, five fidelities

full · ansi256 · ansi16 · plain · json. Removing colour removes nothing: shape, glyph and position still carry every state, so NO_COLOR, CI logs and colour-blind readers get the same information.

05Twelve marks, no dingbats

✓ × ! · › → │ ─ █ ▁…█ — … — every glyph exists in IBM Plex Mono and in the fonts real terminals ship. A mark a font cannot draw is a tofu box in a verification record.

06Motion is a measurement

The spinner is a caliper sweeping a six-cell track, verbs say what is happening, live mode redraws one status line at 1 Hz and never touches scrollback or the alternate screen.

Implementation notes for the Go work that follows

  • One theme.go table generated from tokens.json: role → truecolor / 256 / 16 / plain. Code references roles (verdict.down), never hex values.
  • Fidelity is negotiated once at startup (--color, NO_COLOR, COLORTERM, TERM, isatty) and stored on the output sink; every renderer in output.go reads it.
  • renderTable gains: right-aligned numeric columns, per-column glyph cells, and the probe strip at ≥120 columns only. Below 100 columns tables degrade to kv stacks; nothing is silently elided.
  • Block-element cells (█▇▆…▁) are emitted as glyphs; the mock renderer paints them as cells because that is their Unicode definition and what every terminal font does.
  • Exit codes, --json shape and the —-for-missing rule are untouched. This design adds presentation, never semantics.
